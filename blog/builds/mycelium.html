v2: active dev

this is what i am actively building right now. the vision is one place that is entirely me: a total dashboard, wiki, RAG layer, and personal knowledge graph, all private, offline, and secure by default. nothing leaves the machine unless i explicitly want it to.

the core stack is still being finalized. i am deciding between llama.cpp and ollama or LM Studio as the inference backend. the local models run well, particularly the Qwen MoE which is genuinely fast and capable on my hardware. that said, the architecture will also support connecting to any API endpoint or cloud provider for when i want a smarter model for a specific task. local first, cloud optional.

the wiki layer is multi-domain by design and inspired partly by the Karpathy wiki approach: a knowledge graph that the model itself builds and updates over time. right now the main wiki has 350+ entries across entities, concepts, and auto-generated synthesis notes, seeded from Apple Notes. the taxonomy is intentionally coarse: entity and concept cover almost everything. ingest takes raw notes, classifies them, and writes structured wiki pages. it works.

harvesters in progress: Apple Notes, iMessage, mail, calendar, browser history, local files. the end goal is a personal dashboard that surfaces all of it in one place: wiki search, health logs, a dev project index, everything. Streamlit is the current interface, but that is a placeholder. audio transcription and photo metadata still need preprocessing pipelines before they can ingest. everything else is text and the stack handles it. still a lot to build but the direction is right.

v1: deprecated

enough time passed and I got the itch again to continue dev on my vision of ACRE/Lumen/Mycelium. Around this time, OpenClaw dropped and got me thinking, yes, I dont need to completely re-engineer how MLX is processed and served on mac. So I set out once again to create some sort of skill, wrapper, app, or plugin, that is served locally, accessible thru outlets, and possible to run multi node with prompt processing and all of the bells and whistles. I started dev on this again before I even realized I was trying to make my own open claw. the difference is that it isnt so reliant on cloud models or fancy mcp servers or automated workflows. i want skills, but just the ones I build, not a whole marketplace, way too much security risk IMO. also something about building this perfect vision for myself is much more fun than just running open claw. I also get to learn so much while building.

So I am somewhere well along from what I would call a v1 dev release, being that I have inference running thru ollama on my mac for mlx. it just WORKS! i have a full chroma rag db built out with qwen embedding and node setup scripts that one shot it. so i turned my old desktop into a linux server and set it up as a node to utilize its shitey gpu. same with my old mac pro, a engineering beast, but a bit weak for inference, but tons of ram. both of these are "nodes" in my system, that do cronjobs to pull daily use into the rag db and have some edge gguf models that I dont want on my mac. mac is MLX ONLY!

so I am working on the more interesting capabilities, like chromium playwright browser automation, true agent mode, and other special tasks like code reviewer, biohacker, personal writer, send / receive mail and imessage, personal library, security analyst, trader, poster, and many more. if you cant tell, lots of these tasks are pretty much using all of the projects below in some way.

little did i realize what I wanted was a way to talk to my second brain.
