# nuBlog Developer Wiki (v5.0)

Deep reference for agent contributors. For quick rules and conventions, see CLAUDE.md.

---

## 1. Partial Inclusion Engine (`js/include.js`)

Every page ends with:
```html
<div id="site-header"></div>
...
<div id="site-footer"></div>
<script src="<path>/js/include.js" data-base="<base>"></script>
```

Execution order:
1. Reads `data-base`, validates against page depth, exposes `window.nublogBase`.
2. Immediately appends `js/bot-blocker.js` to `<head>` (scrapers blanked before partials load).
3. Fetches `partials/header.html` + `partials/footer.html`, replaces `%BASE%` tokens, injects into `#site-header` / `#site-footer`.
4. After partials resolve, appends `js/counter.js`.
5. In parallel: `js/oneko.js` (cursor cat), `js/blog-nav.js` (prev/next links — self-gates to `/blog/*.html`).

The `%BASE%` token in partials is always replaced at runtime. Never hardcode paths there.

## 2. Global Styling (`styles/style.css`)

- **Container:** `.content` — 85% width, max 1000px, `padding: 16px 20px`.
- **Typography:** Lucida Grande / Verdana sans-serif stack.
- **Gallery grid:** `.gallery-grid` uses `repeat(auto-fill, minmax(300px, 1fr))`. The gallery index page overrides it via `.gallery-groups .gallery-grid` with a custom property `--gallery-min-width`. Monthly gallery pages use the default.
- **Single stylesheet.** Don't add new `.css` files; extend `style.css`.
- **In-page `<style>` blocks** are acceptable for single-page-specific CSS (boot overlay, spec-box, builds-grid, features grid).

## 3. Bot Defense (`js/bot-blocker.js` + `robots.txt`)

Four layers:
1. `robots.txt` — categorized blocklist of 142 AI crawler agents.
2. Static `<meta name="robots" content="noai, noimageai">` in every HTML `<head>`. Also in build templates.
3. Runtime meta-tag injection — per-crawler opt-out tags + `ai-training: unauthorized`.
4. Active blanking — if `navigator.userAgent` matches the bot regex or `navigator.webdriver === true`, the document root is wiped.

## 4. Interactive Systems

### 4.1 Oneko (`js/oneko.js`)
- Pixel-art cat follows cursor via `setInterval(100ms)`.
- Resolves sprite through `window.nublogBase` → `${base}/images/oneko.gif`.

### 4.2 Blog Nav (`js/blog-nav.js`)
- Self-gates: runs only when `pathname` matches `/blog/*.html`.
- Finds back-link via `a.back-link`, reads the `blogPosts` array (newest-first, auto-generated by build script), injects prev/next links.
- Sets `href` for the back-link to `base + '/blog.html'`.

## 6. QA Checklist

- [ ] `data-base` matches file depth (§6.1 in CLAUDE.md).
- [ ] Ran `python3 scripts/build-sitemap.py` after any file/image changes.
- [ ] `<script src="…/js/include.js" data-base="…">` present; `#site-header` + `#site-footer` divs exist.
- [ ] Back-links correct per page type (blog → `../blog.html`, builds → `index.html`, plants progress → `../../plants.html`, galleries → `../../galleries.html`).
- [ ] Blog posts redirect to `../index.html` when `sessionStorage.nuBlogBootFinished !== 'true'`.
- [ ] All `<img>` and `<iframe>` have `loading="lazy"` and meaningful `alt` attributes.
- [ ] No broken relative paths to CSS, JS, images, or other pages.
- [ ] Bot defense intact — did not remove or weaken `js/bot-blocker.js` or `robots.txt`.
