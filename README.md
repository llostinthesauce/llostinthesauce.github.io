# llostinthesauce.github.io

Personal portfolio website hosted on GitHub Pages

## Overview

A static portfolio website showcasing personal projects, blog posts, and image galleries. Features a retro-inspired design with custom HTML/CSS and an interactive navigation system.

## Tech Stack

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Installation

This is a static website hosted on GitHub Pages. To run locally:

```bash
# Clone the repository
git clone https://github.com/llostinthesauce/llostinthesauce.github.io.git
cd llostinthesauce.github.io

# Open in browser
open index.html
```

Visit [llostinthesauce.github.io](https://llostinthesauce.github.io) to view the live site.
