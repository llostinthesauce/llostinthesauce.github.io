## build

Run `python3 scripts/build-sitemap.py` after adding pages or images. Monthly gallery grids are regenerated from `images/monthly/` with horizontal photos first, then vertical photos; each group is sorted by capture date when available, timestamped filename patterns, or stable filename fallback.
